# Credits & Acknowledgments

Aeon Engine and the Iris UI framework are built on the shoulders of the extraordinary open-source Rust, systems, and computer graphics communities. 

We gratefully acknowledge and credit the following core technologies, libraries, and their authors:

---

## Core Libraries & Ecosystem

- **WGPU & gfx-rs Ecosystem** — Modern, portable, hardware-accelerated graphics API implementation based on the WebGPU specification.
- **Rapier3D & Rapier2D (Dimforge)** — Fast 2D and 3D physics engines for the Rust programming language.
- **hecs (Ralith)** — High-performance, minimalist, archetype-based Entity Component System (ECS).
- **Taffy (Dioxus Labs)** — Flexible, high-performance Flexbox and CSS Grid layout engine powering Iris UI.
- **Cosmic-Text & Glyphon (System76 / Groves)** — Advanced multi-script text shaping, font fallback, and GPU glyph atlas rendering.
- **winit** — Cross-platform window creation and OS platform event loop abstraction.
- **arboard** — Modern, cross-platform system clipboard access library.
- **rfd (Rust File Dialog)** — Native OS open/save file dialog integration.
- **glam & cgmath** — Simple, fast, and feature-rich linear algebra and 3D math libraries.
- **gltf & image** — Khronos glTF 2.0 asset loader and image decompression pipelines.
- **rodio** — High-level audio playback and spatial audio mixing library.
- **serde & serde_json** — Fast, zero-copy serialization and deserialization framework for scene and prefab formats.
- **rayon** — Data-parallelism library powering background file imports and multi-threaded computation.
- **slotmap** — High-performance generational arena array storage.
