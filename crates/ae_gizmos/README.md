# Aeon Gizmos

GPU-free 3D transform gizmo state/math/geometry, collider debug wireframe builders, billboard data, and viewport navigation compass.

## Scope
- **In scope**: `TransformGizmo`, `GizmoMode`, `GizmoSpace`, `DebugShapes`, `BillboardVertex`/`BillboardIconType`, and `SceneNavigationGizmo`.
- **Out of scope**: `wgpu` pipelines and shader compilation (`ae_gizmos_render`).
