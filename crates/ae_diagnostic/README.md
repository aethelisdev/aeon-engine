# Aeon Diagnostic

Zero-dependency frame pacing ring buffers, CPU/GPU pass timings, draw-call breakdowns, VRAM stats, and wall-clock `Profiler`.

## Scope
- **In scope**: `FrameRingBuffer`, `FramePacingStats`, `CpuSyncTimings`, `RenderPassRecordingTimings`, `DrawCallBreakdown`, `VramStats`, and `Profiler`.
- **Out of scope**: GPU/Winit handles and UI widget rendering.
