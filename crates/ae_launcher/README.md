# Aeon Launcher

Standalone project hub executable for creating, browsing, and launching Aeon workspaces in 2D or 3D mode (`ae_editor_app`).

## Scope
- **In scope**: Project creation wizards, recent project manifests, and spawning `ae_editor_app` before exiting.
- **Out of scope**: Runtime scene simulation, GPU 3D rendering, and editor inspector panels.
