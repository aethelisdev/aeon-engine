# Aeon Physics

Decoupled Rapier3D physics simulation, kinematic character controller (KCC), and collider synchronization (`PhysicsWorld`).

## Scope
- **In scope**: Fixed-timestep rigid body/collider stepping, trimesh collider construction, character movement sweeps, and collision/trigger event emission.
- **Out of scope**: 2D physics (`ae-2d-physics`), rendering, and editor UI.
