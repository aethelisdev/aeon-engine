# Aeon 2D Render

WGPU instanced 2D sprite batching and rendering pipeline (`SpriteBatcher`, `Sprite2DPipeline`, `SpriteInstance`).

## Scope
- **In scope**: GPU quad/instance buffers, texture batch splitting, and WGSL 2D shaders.
- **Out of scope**: 3D forward PBR (`ae_pbr`), window management, and asset scanning.
