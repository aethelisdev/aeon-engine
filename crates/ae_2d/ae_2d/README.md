# Aeon 2D

Unified 2D facade composing `ae-2d-core`, `ae-2d-render`, `ae-2d-animation`, and `ae-2d-physics` for `Mode2D` execution.

## Scope
- **In scope**: Dimension mode switches (`ActiveDimensionMode`), `Sprite2DSystem`, `Sprite2DOverlay`, and 2D camera setup.
- **Out of scope**: 3D PBR/shadow rendering and desktop editor panels.
