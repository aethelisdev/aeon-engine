# Aeon 2D Core

Core 2D types, components, sorting keys, and orthographic tracking camera (`Camera2D`, `SpriteRenderer`, `SpriteSortKey`).

## Scope
- **In scope**: 2D camera math, sprite rendering descriptors, and bit-packed 64-bit sort keys.
- **Out of scope**: WGPU device state (`ae-2d-render`) and Rapier2D physics (`ae-2d-physics`).
