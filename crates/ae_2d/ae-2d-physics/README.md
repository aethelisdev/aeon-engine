# Aeon 2D Physics

Rapier2D rigid body simulation, collision detection, and spatial queries (`Physics2DWorld`, `RigidBody2D`, `Collider2D`).

## Scope
- **In scope**: 2D physics world stepping, body types, and box/circle/capsule collider primitives.
- **Out of scope**: 3D physics (`ae_physics`), rendering, and editor UI.
