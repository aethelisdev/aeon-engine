# Aeon Gizmos Render

WGPU `OverlayRenderer` implementations and WGSL shaders for transform gizmos, collider debug wireframes, and 3D entity icon billboards.

## Scope
- **In scope**: `GizmoRenderer`, `DebugRenderer`, `BillboardSystem`/`BillboardPipeline`, and gizmo/debug/billboard WGSL shaders.
- **Out of scope**: CPU gizmo math (`ae_gizmos`) and `winit` windowing.
