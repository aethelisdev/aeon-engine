# Aeon Editor UI

Pure declarative Iris UI panel views, docking workspace layout, and `EngineUiAction` emission for the desktop studio editor.

## Scope
- **In scope**: `EngineUi`, `EngineUiAction`, panel views (`Viewport`, `Hierarchy`, `Inspector`, `Assets`, `Console`, `Stats`, `Preferences`, `Material`, `Timeline`, `UiDesigner`), and asset category badge styling.
- **Out of scope**: Windowing plumbing (`irisui`), OS file dialog spawning, and direct ECS/scene mutation processors.
