# Aeon Camera Controller

Free-fly viewport navigation, orthographic pan/zoom, target focus, and play-mode orbit/2D follow camera controllers.

## Scope
- **In scope**: `step_free_camera`, `pan_orthographic_camera`, `apply_scroll_zoom`, `focus_camera_on_entity`, and `update_follow_camera`.
- **Out of scope**: `wgpu`, `winit`, and editor UI state.
